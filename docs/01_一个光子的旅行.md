# 一个光子的旅行

目的：理解一个光源释放的能量，如何变成一个个具有不同能量的光子；这些光子如何传播、被物体选择性反射、被镜头选择性收集、经过滤光系统，最后在硅中被吸收并产生电子。

为什么曝光增加以后:

```

```

```
        ↓

```

为什么800万像素工业相机不一定比200万像素大像元相机效果好？因为最终成像质量由下述因素决定：

```
Pixel Size
 ↓

 ↓
Photon Collection
 ↓
SNR
```

为什么同一个镜头白天很好晚上噪声大、模糊、色彩偏移？因为Photon不足，Electron不足，Shot noise dominates。

所以，图像不是算法创造出来的，算法只是处理 Sensor 对光子的测量结果。

## 应该如何理解光

很多人学习光学时容易混乱，是因为有时候说“光线”，有时候说“波”，有时候又突然说“光子”。其实它们不是互相矛盾，而是在不同问题下使用不同模型。

| 模型  | 把光看成什么 | 最适合解释 |
| --- | --- | --- |
| 几何光学 | Ray 光线 | 镜头、焦距、FOV、成像、光阑 |
| 波动光学 | 电磁波 | wavelength、干涉、衍射、偏振 |
| 量子光学 | Photon | 光电效应、QE、shot noise、CMOS |
| 电磁理论 | 电磁场 | 折射、反射、传播 |
| 半导体物理 | 能量量子 | photon → electron |

所以今后遇到问题可以先问这个问题应该使用哪一种光模型？比如：

```
“镜头为什么能成像？”
        ↓
几何光学

“为什么小光圈衍射？”
        ↓
波动光学

“为什么 CMOS 会产生电子？”
        ↓
量子 + 半导体物理
```

这些不同的光学模型师是整个光学知识体系的第一块基石。

## 光到底是什么

从典电磁学看光是一种电磁波，它包含相互垂直变化的电场 E 和磁场 B，在真空中的传播速度为3x10^8 m/s。但是到了量子尺度（电磁场的能量交换不是任意连续的，而是量子化的）最小的能量交换单元被称为光子。因此：**光是量子化的电磁场；在传播、干涉时表现出波动性质，在能量交换时表现出光子性质。** 这对于 CMOS 来说尤其重要，因为 CMOS 最终不是“看见一条电磁波”，而是光子在硅基芯片上的堆积。**总结：1.光是一种电磁波，光子是这种电磁波进行能量交换的最小单元。2.一个光子到达coms被硅基吸收，发生一次量子能量交换，产生电子空穴对。**
*<mark>疑问：电子跃迁产生的光子？硅基是如何吸收光子的？量子能量交换是如何发生的？电子空穴对是什么？</mark>*

## 一个光子有多少能量

光子的能量满足：

$$
E=hv 
c=lambda*v
E=hc/lambda
$$

wavelength 决定的是单个 photon 携带多少能量。

$$
(E(eV)≈1240/lambda(nm)
$$

| 光   | wavelength | 单 photon 能量 |
| --- | --- | --- |
| Blue | 450 nm | 2.76 eV |
| Green | 550 nm | 2.25 eV |
| Red | 650 nm | 1.91 eV |

波长越短，每个光子的能量越高。

## Photon 产生之后是怎么运动的？

不要简单想象光源发射一个小球自由空间传播，这是经常出现的一个容易被“粒子小球模型”误导的现象。在自由空间传播时，更适合使用**电磁波 / 量子电磁场传播**。在均匀介质里光沿直线传播，进入不同介质时方向可能发生变化，即折射定律：

$$
n_1*sin（theta_1）=n_2*sin（theta_2)
$$

电磁场与材料中的电荷发生相互作用，使传播的相位关系发生变化，因此宏观表现为折射率 \(n\)。

![](file://C:\Users\Noah\AppData\Roaming\marktext\images\2026-09-27-08-47-36-image.png?msec=1790598741382)

一个 photon 到达物体之后，主要可能发生：

```
            Photon
               ↓
            Object
    ┌──────────┼──────────┐
    ↓          ↓          ↓
Reflection  Absorption Transmission
  反射         吸收        透射
```

也有可能发生分散、荧光、折射，一般机器视觉主要考虑反射和吸收。

每个物体单元都具有对应的光谱反射率，即对每个 wavelength 反射多少。

一个 photon 可能经历：

```
Air
 ↓
Lens surface
 ↓
AR coating
 ↓
Glass
 ↓
Lens element
 ↓
Air gap
 ↓
Lens element
 ↓
...
 ↓
Aperture
 ↓
Sensor
```

每一个表面都可能Transmission、Reflection、Absorption、Scattering

## 镜头究竟干了什么？

镜头是把来自同一个 object point、不同方向传播的 photons，重新汇聚到 image plane 中的同一个位置附近。

```
Object Point
     ●
    /|\
   / | \
  /  |  \
 /   |   \
     ↓
   [ LENS ]
      \│/
       ●
    Sensor
```

```
Object 发出大量 photons
                ↓
         ┌──── Lens ────┐
         │              │

大 aperture
        ↓
允许更大的 solid angle
        ↓
更多 photons 被收集
        ↓
更多 photons 到 Pixel
        ↓
更多 electrons
```

光圈还会影响：球面像差、昏迷、散光、场曲、色差、景深

```
大光圈
│
│ aberration 较强
│
↓
中等光圈
│
│ 通常分辨率最好
│
↓
很小光圈
│
│ diffraction（衍射） 开始主导（光是波，当一个波经过有限 aperture时波会扩展开）
↓
```

有限尺寸 aperture 对电磁波空间波前进行了截断，由此导致不同部分波前在 image plane 发生干涉，形成 Airy pattern。

## 为什么 Silicon 能探测可见光？

硅带隙约为1.12eV，对应波长为1240/1.12=1100nm，所以从能量角度光子能量需要大于硅带隙才有可能有效产生载流子，这也是为什么普通 Silicon CMOS 的长波响应大约延伸到1000–1100 nm，因此普通 Silicon CMOS对波长大于1100nm的光子响应逐渐接近零。

```
UV     Visible          NIR
│         │              │
└─────────┴──────────────┘
          可以响应

                   ~1100nm
                      │
                      ▼
响应逐渐接近零
```

## 什么相机通常要加 IR-Cut？

因为 silicon 对700–1000nm附近的近红外仍然具有明显响应（人眼基本看不见这些光，但 CMOS 看得见），所以如果不去掉 IR会造成颜色严重偏差。

## 为什么 CMOS 不能直接“感知颜色”？

普通 silicon photodiode（硅基光电二极管） 做的事情本质上只是吸收光子形成电子空穴对，传感器光谱响应加权后不同两束光可能产生相同数量的 electrons，因此普通 silicon pixel 无法根据输出电荷，反推每个 photon 原本是什么 wavelength，这就是CMOS 不能直接测量颜色的原因。

## 相机颜色怎么来的？

Color Filter Array，最典型Bayer CFA是：（RGGB 是四个物理 pixel，不是一个 pixel）

```
┌─────┬─────┐
│  R  │  G  │
├─────┼─────┤
│  G  │  B  │
└─────┴─────┘
White light
 ↓
[ RED FILTER ]

Red   ──────────→ Silicon
Green ──X
Blue  ──X

White light
 ↓
[ BLUE FILTER ]

Red   ──X
Green ──X
Blue  ──────────→ Silicon


所以 CMOS 不是检测出了 photon 的颜色，而是在 photon 到达 silicon 之前，用 CFA
把光谱进行了一次粗略筛选。
```
